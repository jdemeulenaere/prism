# Tasks

Fixtures go under `crates/prism-cli/tests/fixtures/<spec>/`, one case per scenario, or per form of a scenario with several (`<scenario-slug>--<form>`), as the header of `fixture_tests.rs` describes. Cross-file scenarios use a case directory with package subdirectories and an `// entry:` line. The ABI hash scenarios are Rust tests in `crates/prism-abi/tests/abi_scenario_tests.rs` over real `.prism` source, named after their scenarios, like the existing hash tests.
