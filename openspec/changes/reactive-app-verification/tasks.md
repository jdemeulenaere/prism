# Tasks

The apps live under `examples/` (design D2), and their sessions beside them (D4). Fixtures of single rules go under `crates/prism-cli/tests/fixtures/<spec>/<scenario-slug>[--<form>]/`, as the header of `fixture_tests.rs` describes, and run under `--check-allocations`. "The counter screen" and "the typing app" mean `ui-toolkit`'s composables of the scenarios "Counter screen" and "Typing into a text field", run by `fun main() { runApp(width = 400, height = 300) { ... } }`. A bug in an earlier change that the apps hit is fixed in its own commit as a plain fix with a regression fixture, and a missing feature is written around and becomes a follow-up (D3); record each in the commit message of the group that found it.

Prerequisites (design, "Baseline"): `standard-library`, `compose-runtime`, `compose-transform`, `state-handles`, `ui-toolkit`, `desktop-window` and `compose-hot-reload` are archived. Groups 1 to 6 need only `ui-toolkit` and `compose-hot-reload` and what they bring. Task 5.4 and group 8 also need `desktop-window`.

## 5. Frame statistics (D7, D8)
