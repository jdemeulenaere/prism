# Tasks

Fixtures go under `crates/prism-cli/tests/fixtures/<spec>/`, one case per scenario, or per form of a scenario with several (`<scenario-slug>--<form>`), as the header of `fixture_tests.rs` describes. New `patterns` scenarios go under `fixtures/patterns/`. Runtime scenarios (`execution`) are executable fixtures run with `--check-allocations`. This change assumes `codegen-aggregates` and `runtime-strings-and-drops` have landed. Check that before starting, and stop if they have not.
