# Tasks

Fixtures go under `crates/prism-cli/tests/fixtures/<spec>/`, one case per scenario, or per form of a scenario with several (`<scenario-slug>--<form>`), as the header of `fixture_tests.rs` describes. Every program is an executable case (`// run: <status>` with `stdout.snap` and `stderr.snap`), which the runner runs with `--check-allocations`, so each also asserts that no allocation leaks or is freed twice. Prerequisites (design, "Baseline"): `payload-patterns`, `heap-boxes`, `monomorphization`, `closures` and `escaping-closures` are archived; `GlueKind::Equals`, the stack check of glue, `contents_writable` through boxes, instance units and function values named below come from them. Before starting, compare the three MODIFIED blocks of the deltas with the main specs and reconcile any drift.
