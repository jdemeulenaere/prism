# Tasks

The cache scenarios are integration tests in `crates/prism-cli/tests/cache_tests.rs`, as in `abi-cache`. Each builds a workspace and a cache in temporary directories, runs the `prism` binary with `PRISM_CACHE` set, edits files between runs, and compares the `--explain-cache` lines and the program's output. Each test is named after the scenario it protects (snake case of its heading). ABI scenarios are tests in `crates/prism-abi/tests/abi_scenario_tests.rs`, and hash scenarios that no CLI output shows are tests that hash records built from real `.prism` source.

Before starting, check every function this file attributes to `monomorphization` (`GenericRecord`, `GenericRecord::of_file`, `instantiate`, `collect_instances`, `InstanceUnit`, `instance_symbol`, `check_instances`, `Linker::add_instance`, `dump_instances`, `growing_cycles`) against the landed code, and compare every MODIFIED block of the deltas with the main specs as `monomorphization` left them (design, "Baseline"). Reconcile any drift in the deltas first.
