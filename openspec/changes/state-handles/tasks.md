# Tasks

Fixtures go under `crates/prism-cli/tests/fixtures/<spec>/<scenario-slug>[--<form>]/`, as the header of `fixture_tests.rs` describes. Every executable case (`// run:`) runs under `--check-allocations`. Scenarios whose WHEN names a Rust test or a benchmark are tested where their task says.

Prerequisites (design, "Baseline"): `compose-transform` archived, and with it `compose-runtime`, `standard-library`, `collections`, `instance-cache` and `hot-reload`. None of `compose-runtime`, `compose-transform`, `standard-library`, `instance-cache` or `hot-reload` was implemented when this change was proposed, and `collections` was being implemented, so the names this list takes from their packets (`thread.rs`, `Handle`, `slot.rs`, `composition.rs`, `COMPOSE_FUNCTIONS`, `UnitContext::entry_point`, `UnitContext::slot_type`, `set_finish_report`, `intrinsics.rs`, `PRELUDE`, `ComposerOperation`, `MirPhase::Composed`, the `remember` lowering in `prism-compose-transform/src/intrinsics.rs`, the record codec) must be checked against their code first. Before group 1, read the main specs those changes leave for `compose`, `standard-library`, `code-generation` and `execution`, and reconcile every requirement name and dump format this change's deltas cite (the `slot` dump line, `composer <operation>` in composed dumps, the `E4029` messages), adjusting the deltas where they drifted.
