# Tasks

Fixtures go under `crates/prism-cli/tests/fixtures/<spec>/<scenario-slug>[--<form>]/`, as the header of `fixture_tests.rs` describes. Every executable case (`// run:`) runs under `--check-allocations`. Scenarios whose WHEN names a Rust test, a CLI test or a benchmark are tested where their task says.

Prerequisites (design, "Baseline"): `compose-runtime` archived, and with it `closures`, `escaping-closures`, `standard-library`, `collections`, `monomorphization`, `instance-cache` and `hot-reload`. None of `compose-runtime`, `standard-library`, `instance-cache` or `hot-reload` was implemented when this change was proposed, so the names this list takes from their packets (`COMPOSE_FUNCTIONS`, `UnitContext::entry_point`, `intrinsics.rs`, `PRELUDE`, `TypeFingerprints`, the record codec) must be checked against their code first. Before group 1, compare every MODIFIED block with the main specs as those changes left them and reconcile any drift in the delta: `code-generation` "Each Closure Has a Descriptor", "Constructs the Backend Lacks Are Rejected Before Code Generation", "Cranelift IR Dump" and "The Backend Checks Each Instance", and `standard-library` "The Compiler Ships the Library", "Library Modules Compile Like Workspace Files" and "Intrinsic Calls Are Typed by Their Signatures". Also check that `prism_compose_set_slot` releases a replaced value of the matching type at the end of the pass, which D8's "different" path and D12's changed keys rely on, and extend it in `prism-compose` if it does not.
