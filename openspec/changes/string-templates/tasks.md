# Tasks

Fixtures go under `crates/prism-cli/tests/fixtures/<spec>/`, one case per scenario, or one per form of a scenario with several (`<scenario-slug>--<form>`), as the header of `fixture_tests.rs` describes. Programs are executable cases (`// run: <status>` with `stdout.snap` and `stderr.snap`), which run under `--check-allocations`. Token-level scenarios are Rust tests in `crates/prism-lexer/tests/scenario_tests.rs`, tree-level ones in `crates/prism-parser/tests/scenario_tests.rs`, layout ones are golden files in `crates/prism-formatter/tests/golden/` named after their scenario slugs, and scenarios about `prism dump-clif` or about whether a program allocates are Rust tests (codegen or CLI tests), not fixtures. Read every blessed snapshot against its scenario's THEN before committing it. `runtime-strings-and-drops`, `payload-patterns` and `heap-boxes` must be archived before this change starts (`design.md`, Context).

## 1. Lexer (D2, D3, D4)

- [ ] 1.1 In `crates/prism-lexer/src/token.rs`, add `TokenKind::TemplateStart`, `TemplateText(String)`, `TemplateName(String)`, `TemplateExpressionStart`, `TemplateExpressionEnd` and `TemplateEnd`, with `Display` forms `"`, the text, `$name`, `${`, `}` and `"`. In `lexer.rs`, add `'$' => Ok('$')` to `lex_escape`. Verify with lexer tests for "Dollar sign escape" in strings and `Char` literals, and that the existing unknown-escape tests still pass.
- [ ] 1.2 In `lexer.rs`, add a mode stack to `Lexer` (`Template`, and `TemplateExpression { open_braces }`). Make `next_token` dispatch to a new `lex_template_text` in `Template` mode, without skipping whitespace or comments, which returns the next text run (escapes decoded through `lex_escape`), a `TemplateName` (rejecting keywords other than `this` through `TokenKind::keyword_from_str` with an `Error` naming the keyword), a `TemplateExpressionStart` (pushing `TemplateExpression { open_braces: 0 }`), or `TemplateEnd` (popping). In `TemplateExpression` mode, count `{` and `}` and return `TemplateExpressionEnd` for the `}` at depth 0, popping the mode. Make `lex_string` save the position after the opening quote and, at the first `$` that starts a part, restore it, push `Template` and return `TemplateStart`. A literal without parts still returns `String`. A raw newline in template text returns an `Error` and pops `Template` without consuming the newline. At the end of the file, an open mode returns one `Error` ("Unterminated string template") and clears the stack, then `Eof`. Verify with lexer tests for "Template tokens" (spans included), "Adjacent parts and this", "A dollar sign that starts no part", "Braces and strings inside an expression part", "A keyword after a dollar sign rejected", every form of "Unterminated templates rejected" (no panic, no infinite loop, `Eof` last), and "Comment-collecting lexer inside templates" (`tokenize_with_comments` gives the same tokens as `tokenize_all`).

- [ ] 5.2 In `crates/prism-typechecker/src/checker.rs`, check `ExprKind::Template` in `infer_expr_kind` through a new `check_template_part` per part. Fixtures check codes only, so also check each message and help of D8 (with the part's own text in the `?:` help) with tests in `crates/prism-typechecker/tests/regressions.rs`.
