# Tasks

Fixtures go under `crates/prism-cli/tests/fixtures/<spec>/`, one case per scenario, or per form of a scenario with several (`<scenario-slug>--<form>`), as the header of `fixture_tests.rs` describes. Programs are executable cases (`// run: <status>` with `stdout.snap` and `stderr.snap`), and the runner runs every one with `--check-allocations` (`runtime-strings-and-drops`), so each also asserts that nothing leaks or is freed twice. Scenarios about `prism dump-clif` or about whether a program allocates are Rust tests (codegen or CLI tests), not fixtures. Read every blessed snapshot against its scenario's THEN before committing it.

Prerequisites (D1): `codegen-aggregates`, `runtime-strings-and-drops` and `payload-patterns` are archived. `glue.rs`, `GlueTable`, `prism_rt_allocate`/`prism_rt_free`, `allocation_statistics()`, `patterns.rs`, `exhaustiveness.rs` and `build/pattern.rs`, named below, come from them.
